# R57 整體模組優化

基線：R56，`20c25f66c1c01a4d2199b217ed22c312a4423dd7`。
同一 Sites 專案與既有架構；v4.3.2 保持凍結。

## 檢查範圍與處理

| 模組 | 處理 |
| --- | --- |
| 公司、薪資、加班、請假、補休 | 共用已儲存請假紀錄的日期展開結果與成員索引；草稿即時計算。儲存、失敗回復及匯入沿用既有快取清除流程。基本月薪、津貼、加班倍率、月結取整及扣薪公式維持原邏輯。 |
| 首頁、投資、年度投資收入 | 共用同一個投資計算結果。僅保留目前年度／日期的一份；儲存、資料替換、年度切換、跨日均會重新取得結果。 |
| 股票交易、持股、配息、行情 | 配息預估由每個除息日期重跑 FIFO，改成一次 FIFO 後查詢各日期的歷史股數。採用既有事件結餘，保留分割、部分賣出、零股、期初持股與浮點容許誤差。交易驗證改用股票 ID 索引，數字格式器重用。行情服務、更新間隔、來源及傳輸內容保持原流程。 |
| 年度分析 | 一次建立公司／年度／月份範圍索引；所有加總維持原資料順序及取整方式。 |
| 一般／加密備份、SmartPortfolio 匯入 | 備份合併建立 ID 與內容索引；保留同 ID 優先、模糊衝突拒絕、關聯重映射及覆蓋／副本／還原語意。加密格式、金鑰推導及 SmartPortfolio 轉換流程不改動。 |
| Google Drive | 保留原使用者帳戶、授權、逾時、檔案限制與自動備份延遲。沒有加入新伺服器或傳送私人資料；本次沒有執行使用者帳戶的雲端寫入驗收。 |
| 中英文、選單、表格、各介面風格 | 移除一次整頁重複翻譯；變動文字僅翻譯相關區域，並合併父子重疊範圍。表格捲動列忽略無關訊息、合併同畫格更新，先量測再寫樣式，且不再觸發整頁翻譯。保留原 CSS、減少動態設定與 R55／R56 操作樣式。 |

資料 KEY `salarymate_v5_full_state`、Schema 15、備份結構及本機保存方式保持一致。所有新索引／快取都只在記憶體，不寫入備份。

## 合成資料效能量測

單一 Node 執行環境；暖機一次、三次測量取中位數。前後版本順序執行，沒有瀏覽器、網路或使用者私人資料。資料為 30 檔股票、3,000 筆交易、20 個配息日期、600 筆備份比對、7,200 筆薪資。數值屬運算／HTML 產生時間，不能當成手機整頁載入或實際觸控速度。

| 工作 | R56 | R57 | 耗時減少 |
| --- | ---: | ---: | ---: |
| 投資頁 HTML 產生 | 20.52 ms | 6.85 ms | 66.6% |
| 配息預估 | 84.56 ms | 11.73 ms | 86.1% |
| 備份合併 | 865.74 ms | 5.65 ms | 99.3% |
| 年度分析 | 80.86 ms | 51.76 ms | 36.0% |

FIFO 本身未改演算法；單次量測的 8.89 → 7.85 ms 差異不列為演算法改善。可重現命令：

```sh
node scripts/r57-benchmark.mjs --baseline
node scripts/r57-benchmark.mjs
```

完整量測在 `R57-PERFORMANCE-RESULTS.json`。單一文字變動的物件測試中，翻譯走訪由 400 個文字節點縮為 1 個；同一投資頁的 FIFO 呼叫由 2 次降為 1 次。

## 驗證

- 62 項既有程式測試通過：R38 加班取整、R42 公司薪資與扣項、R46 行情同步，以及年度、補休、月結核對、複製月份。已包含 9 月 76 小時加班費 19,665 元案例。
- 9 項新計算／相容性測試通過：96 組配息日期與排除設定比較、分割／期初／入帳邊界、FIFO 結果、備份模式與衝突、年度範圍、快取失效、請假草稿，以及六個投資頁 HTML 逐字一致。
- 4 項新畫面工作量測試通過：局部翻譯、重疊變動合併、選項值與私人文字保護、中英切換、表格排程及無關變動忽略。
- 合計 75 項程式測試。測試使用 Node VM 與有限物件測試資料，沒有啟動虛擬瀏覽器或 DOM 模擬器。
- 手機實機視覺、滑動與端到端效能尚未驗收，不宣稱 PASS。

本輪優化聚焦已量測的重複運算；不因模組列在檢查範圍，就對已具備快取／節流的來源服務、授權流程或財務公式作額外改寫。
