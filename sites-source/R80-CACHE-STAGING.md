# R80：重開快取與晶羽素材分階段載入

延續已發布 R79，沿用原 Sites 專案與架構。保留六張背景、晶羽高解析飛行、施法姿勢、十種風系魔法與螢幕震動。

## 已完成

- 目前版本的 CSS／JavaScript 優先使用 Service Worker 快取。固定版本檔名的背景及晶羽素材也優先讀快取，同時請求合併，命中時不重寫。
- Sites 對目前版本的 CSS／JavaScript 查詢網址及具版本檔名的圖片提供一年 immutable HTTP 快取。HTML、Service Worker 及未版本化程式仍需確認更新，避免介面停留在舊版。
- 晶羽圖片移出必須成功的安裝預載清單；首頁不提前下載全部飛行與魔法圖。使用圖片風格時，當前背景與停駐晶羽仍會正常載入。
- 已下載圖片存在獨立素材快取，之後升版可繼續使用。從 R79 更新時先搬移已快取素材，再移除舊介面快取；搬移失敗保留舊快取供回退，不重新下載。
- 點擊晶羽時準備四張飛行圖並解碼實際顯示節點。原位置持續顯示至飛行準備完成，保留取消與載入失敗處理。
- 可見起飛 120 ms 後才準備施法姿勢與本次第一招素材；第二招在預定施放前 2.4 秒開始準備。只載入本次兩招需要的圖。
- 使用同一動畫迴圈，不增加計時器。取消後不啟動後續階段；背景暫停後若已錯過施法時點，也不補下載已錯過的素材。
- 可選素材較慢或離線未快取時不阻塞起飛。已快取圖片可離線使用；尚未下載的圖片第一次仍需連線，失敗後可重試。
- API 與個人帳務資料不納入上述圖片／版本檔案快取，資料 KEY、Schema 15、備份與自己的 Google Drive 流程均不變。
