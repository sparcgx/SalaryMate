# 個人薪資管理 v3.6.1｜行動版修正與效能優化

## 維護範圍

- 對外產品名稱統一為「個人薪資管理」；既有 Sites 專案識別、網址與 `salarymate_v310_state` 儲存鍵維持不變，避免使用者資料中斷。
- 手機版表單控制項至少使用 16px 字級，避免 iOS Safari 編輯薪資後觸發頁面自動放大。
- 關閉表單前主動解除欄位焦點，並在畫面穩定後還原開啟前的捲動位置與觸發元件焦點。
- 觸控裝置開啟表單時不自動聚焦文字／數字欄位，避免鍵盤與縮放未經使用者操作即出現。
- 重用數字格式化器，快取目前年度／公司的薪資、出勤與時薪分析結果；資料變更時統一清除快取。
- 月度薪資趨勢改為單次掃描彙總，避免針對 12 個月份重複過濾全部薪資紀錄。

## 資料相容性

- Schema 維持 10，未新增或移除使用者資料欄位。
- JSON 備份的正式應用名稱改為「個人薪資管理」，備份與 CSV 檔名同步更新。
- v3.6.0 以前的瀏覽器資料可直接載入，不需另做遷移。

## 股票管理適配結論

- 本版不加入股票管理。
- 股票部位、交易成本、即時報價與投資稅務屬於不同資料生命週期，直接塞入薪資核心會增加隱私、資料來源、效能及操作複雜度。
- 後續若要規劃，建議做成獨立、可選用的「投資資產」模組，只由薪資端單向提供每月可投資金額；第一階段採手動持倉，不含下單與即時行情。

## Release Gate

開發中預檢：

```bash
node tests/release-gate.mjs --allow-dirty
```

正式發布仍需使用者另行下達發布指令；此維護工作不會自動覆蓋目前線上的 v3.6.0。
