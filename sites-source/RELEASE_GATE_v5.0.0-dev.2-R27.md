# R27 — 薪資列透明度殘留修正

使用者 R26 實機截圖顯示未懸停薪資列仍為實色。

根因：舊 :is() 包含 .dialog-body .card，將整組優先權提高至 (0,4,1)，超過 R26 透明規則 (0,3,3)。JSDOM 的 computed style 檢查未捕捉實際瀏覽器的此優先權差異。

修正：拆開巢狀 dialog card 規則；舊薪資列規則降為 (0,3,1)，由 R26 的 (0,3,3) 正確覆寫。首頁最近薪資與日曆同組規則一起修復。主選單與頂部操作列固定底色保持。

驗證：針對實際規則的 CSS 優先權核對、建置及 JavaScript 語法檢查；依使用者偏好未使用虛擬瀏覽器。實機視覺待使用者確認。
