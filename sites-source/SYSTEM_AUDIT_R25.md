# 全系統檢查與修正 — R25

檢查日期：2026-10-04（台灣時間）。範圍為目前 v5 網站、單一 HTML 版、股票服務模組，並交叉檢查 v4.3.2 日曆版入口與歷史驗收。

## 已重現並修正

1. **文字與密度儲存失敗仍顯示成功**：改成安全提交；失敗時還原畫面、記憶體資料及選項，不再顯示成功訊息。
2. **清除資料後介面設定重新出現**：原本先存檔才重設介面，重開會讀回舊偏好。改為同次提交預設值；清除失敗則完整還原。測試僅使用隔離測試資料，未清除使用者資料。
3. **試算資料寫入失敗沒有還原**：加班試算的欄位、倍率、時數、帶入薪資、重設及時薪設定改為安全提交，失敗不留下未儲存的記憶體值或成功提示。計算公式未變更。

## 測試基準問題與未驗證範圍

- 舊股息測試把第一個表格當作實收股息表；新增預計配息後該選擇器已過期。已改為精準選取實收表，除息日、現金股利、編輯、備份與 CSV 原有斷言全部保留並通過。
- 原 `npm test` 的歷史 v4.3.2 凍結套件為 **57 通過、4 失敗**。失敗為舊 SHA-256／全目錄清單及舊快取版本假設，与已加入日曆切換的 calendar1 與 v5 並存版本不符。沒有改寫舊凍結雜湊或刪除斷言來掩蓋差異。故原歷史發布門檻仍不是全綠，不能以本報告宣稱通過該凍結門檻。
- 原凍結的既有檔案中有差異者：`dist/app.js`、`dist/bootstrap.js`、`dist/index.html`、`dist/styles.css`、`dist/sw.js`。本次未修改這些 v4 檔案。
- 股價、配息與 Google Drive 使用模擬回應驗證流程，未執行使用者帳戶的實際登入／上傳或即時交易所端到端驗證。
- 遵循使用者偏好，未使用虛擬瀏覽器；手機、Safari、實際模糊效果與最終排版仍需實機驗收。
