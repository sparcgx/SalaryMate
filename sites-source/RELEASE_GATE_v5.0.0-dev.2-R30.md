# R30 — 動態霧面玻璃及投資操作簡化

- 動態霧面玻璃主題增加背景色層、流動幅度與霧面 blur/saturate，強化高光及陰影；遵循減少動態／透明效果偏好及無 backdrop-filter 回退。
- 主選單固定底色與其他主題透明度規則維持。
- 股票頁移除手動價格及匯入 SmartPortfolio 入口；設定中的備份相容能力保留。
- 頂部動作縮為更新、新增、交易、批次。
- 手機標題右側選項開關，支援 Escape、外部點擊及焦點離開關閉；桌面保留直接操作。

驗證：中英文 DOM 行為、入口移除、選單開關／Escape／外部點擊、新增股票視窗、CSS 解析與 JS 語法通過。未使用虛擬瀏覽器，實機視覺待使用者確認。
