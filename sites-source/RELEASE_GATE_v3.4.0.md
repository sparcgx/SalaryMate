# SalaryMate v3.4.0｜Regression＋Release Gate

## 判定規則

執行：

```bash
node tests/release-gate.mjs
```

只有所有硬性門檻均通過，終端顯示 `RELEASE GATE: PASS`，才可建立並發布 v3.4.0 Site 版本。任何一項失敗一律判定 `HOLD`，修正後必須從頭重跑完整 Gate。

開發中可使用 `node tests/release-gate.mjs --allow-dirty` 預檢；此模式不驗證工作樹已封存，因此不能作為正式發布依據。

## 硬性門檻

| Gate | 驗證範圍 | 主要阻擋條件 |
|---|---|---|
| G01 | Sites 設定與入口 | project ID、`dist` 目錄或入口不一致 |
| G02 | 版本與資料契約 | App 版本、Schema 8、儲存 key 或畫面版號不同步 |
| G03 | 靜態回歸 | JavaScript 語法、手機版防護、必要功能標記或可攜性失敗 |
| G04 | 執行期回歸 | 啟動、舊資料遷移、公司隔離、計薪區間、請假流程、額度、扣款連動、匯出／還原任一失敗 |
| G05 | 資產完整性 | 外部執行期依賴或遺失的本機資產 |
| G06 | 資料安全 | 提交 `.env`、私鑰、憑證或常見服務 token |
| G07 | Git 差異品質 | 衝突標記、尾端空白或不合法差異 |
| G08 | 候選來源封存 | 正式執行 Gate 時工作樹仍有未提交內容 |
| G09 | 可視化預覽設定 | 預覽未直接使用正式 `dist`、缺少手機／平板／桌機裝置框、受控主機設定或 Vite 未封存 |

## Phase 1–4 回歸範圍

- Phase 1：Schema 8 遷移、第一天上班日、公司每日工時、日曆月／前月 16 日至本月 15 日區間。
- Phase 2：請假狀態、跨區間拆分、重疊與同日加班警示、薪資扣款同步／更新／解除與防重複。
- Phase 3：自動／自訂／無上限額度、週年制／曆年制、已用與預留時數、超額警示、12 個月出勤分析。
- Phase 4：公司與月份隔離、手機公司儲存與資料選單、CSV 公式注入防護、JSON 備份還原、非破壞性資料健檢與發布來源完整性。

## 發布邊界

- 本 Gate 驗證本地候選來源是否可發布，不會自行建立 Site 版本或部署正式站。
- 執行 `npm run dev` 可直接預覽正式 `dist` 內容。
- 開啟 `http://localhost:5173/__preview?device=mobile` 可使用 390 × 844 手機裝置框；將 `device` 改成 `tablet` 或 `desktop` 可切換平板與桌機尺寸。
- 裝置框與一般預覽共用同一份正式 `dist`，瀏覽器視覺巡檢通過後才進入正式站部署。
