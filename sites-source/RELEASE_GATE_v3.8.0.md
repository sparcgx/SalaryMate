# 個人薪資管理 v3.8.0｜多介面模式與資訊架構優化

## 功能範圍

- 新增「介面與版面」中心，提供四種可即時切換的介面模式：
  - 清爽卡片：完整卡片、圖表與輔助說明，延續 v3.7.0 的預設體驗。
  - 極簡清單：移除多餘陰影與裝飾，強化文字和金額辨識。
  - 高效緊湊：縮短卡片、表格與頁面間距，提高單頁資訊密度。
  - 大字易讀：放大常用文字、欄位與按鈕，改善長時間與觸控操作。
- 介面模式會即時套用、自動保存，重新開啟網站後仍維持上次選擇。
- 所有模式共用同一套薪資資料與計算核心，不建立重複資料、不改寫歷史紀錄。

## 結構優化

- 主要導覽依工作目的分成「日常管理」與「分析與規劃」。
- 日常管理：收入總覽、薪資明細、工時出勤。
- 分析與規劃：加班／年終／調薪試算與年度對帳。
- 右上功能選單重整為「系統設定、備份與匯出、資料維護」三層，並新增全域公司與薪資規則入口。
- 導入共用版面 Token，集中管理內容寬度、頁面間距、卡片間距、圓角與控制項高度，避免各模式分散修改結構。
- 手機版仍維持底部五項主導覽；模式只調整密度和層級，不改變功能位置與操作流程。

## 資料相容性

- Schema 由 11 升級為 12，只新增 `uiPreferences.interfaceMode` 顯示偏好。
- v3.7.0 與更舊備份缺少此欄位時，自動使用「清爽卡片」。
- `salarymate_v310_state` 儲存鍵維持不變。
- 公司、薪資、加班、請假、年終、調薪與試算公式未變更。
- 匯出 JSON 會保留介面偏好；匯入舊備份仍可正常升級。

## Release Gate

開發中預檢：

```bash
node tests/release-gate.mjs --allow-dirty
```

正式發布需由使用者另行下達發布指令；本次建置不會自動覆蓋線上 v3.7.0。
