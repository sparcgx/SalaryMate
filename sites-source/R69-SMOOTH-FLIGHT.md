# R69 — 晶羽飛行視覺平順化

沿用 R68 的九姿勢透明飛行素材，改善點擊晶羽後的拍翅、轉彎與起降連續性。

- 以兩層姿勢漸進混合銜接拍翅；不支援加色混合時保留單層顯示。
- 路徑節點共用切線，依曲線弧長前進，加入起飛加速與回位減速。
- 使用小幅側傾與俯仰轉彎，移除整張圖片的 180 度翻面。
- 依實際時間平滑姿態，支援不同更新頻率；滑翔與降落保留連續拍翅相位。
- 起飛前完成圖片解碼，減少首次切換停頓；移除飛行精靈上的動態陰影濾鏡。
- 保留再次點擊、捲動、縮放、切頁、開啟對話框與離開頁面時的清理，以及減少動態效果設定。

## 驗證

- JavaScript 語法與差異空白檢查通過。
- R57/R65 既有六項回歸測試通過。
- Node VM 模擬 30/60/120 Hz 更新：7,313 個位置樣本在邊界內，4,283 個混合樣本的權重總和維持 1。
- 九種姿勢、單一動畫迴圈、結束與中止清理、等待圖片解碼時取消、減少動態與單層相容模式通過。
- 上述為程式模擬，並非實測幀率。未使用虛擬瀏覽器；手機實機視覺驗收仍待確認。

資料鍵與 Schema 15、備份與 Google Drive 流程維持既有設計；凍結的 v4.3.2 不變。
