## 變更與使用

入口：設定 → 介面與版面 → 動態玻璃。

| 選項 | 表現 |
| --- | --- |
| 一般 | 高不透明度、較少模糊、無持續背景動畫 |
| 精細（預設） | 霧面玻璃、柔和陰影與視窗過場 |
| 高動態 | 動態背景流光、頁面過場，滑鼠裝置增加局部光澤與懸停回饋 |

保持白底、深色文字，卡片、導覽及視窗增加透明層次。沿用原有四種版面與六種配色，外觀強度獨立記憶。觸控装置不追蹤游標，也不要求動作感測權限；背景分頁暫停持續動畫。

使用系統「減少動態效果」時，保留使用者選擇並停用動畫與互動流光；系統「減少透明度」及不支援背景模糊時使用實色後備樣式。這些媒體設定以瀏覽器實際回報為準。

## 資料與版本範圍

- 新偏好鍵：`salarymate.visualEffects.v1`，只儲存 `normal`／`fine`／`dynamic`。
- 薪資仍使用 `salarymate_v310_state`、Schema 13、相同網站來源。新外觀模組不讀寫薪資鍵、不刪除資料、不發出網路請求。
- `app.js` 僅更新 APP_VERSION 與加入設定區塊呼叫；`bootstrap.js` 僅更新版本與資產網址。財務數字、匯入匯出、跨公司處理、資料遷移及安全流程沒有程式變更。
- 瀏覽器外觀偏好不加入薪資備份；薪資備份的應用程式版本中繼資料更新為本版本。
- PWA 增加新外觀資產及獨立快取版本。清理範圍維持既有的 `salarymate-shell-*` 資產快取，不清除 localStorage。
- 不改寫 `stable/v4.3.0`／`freeze/v4.3.0` 凍結來源；原有發布紀錄保留作為歷史證據。
