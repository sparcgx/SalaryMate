# 個人薪資管理 v3.9.0｜手機導覽與全模式配色

## 功能範圍

- 修正手機底部選單偶發消失：主要導覽已從黏性頂端列移出，改為獨立固定層。
- 補齊 iPhone 安全區、穩定層級、硬體合成與頁面底部保留空間，避免內容或選單互相遮擋。
- 手機主內容支援左右滑動快速換頁，順序為「收入總覽 → 薪資明細 → 工時出勤 → 試算規劃 → 年度對帳」。
- 保留瀏覽器邊緣返回手勢，並排除表格、輸入欄位、按鈕、連結與內頁籤，避免橫向操作誤觸換頁。
- 「介面與版面」新增六組配色：翡翠綠、海洋藍、靛青紫、暖陽橘、莓果紅、石墨灰。

## 全模式規則

- 四種版面模式「清爽卡片、極簡清單、高效緊湊、大字易讀」皆可套用全部六組配色。
- 版面模式與配色主題是兩個獨立偏好：切換版面不重設顏色，切換顏色不改變版面。
- 配色會同步套用主要按鈕、導覽選取狀態、頁籤、圖表重點、焦點框、品牌標記與試算頁主視覺。
- 所有組合共用原有資料與計算核心，不建立重複資料、不改寫歷史紀錄。

## 資料相容性

- Schema 由 12 升級為 13，新增 `uiPreferences.colorTheme` 顯示偏好。
- v3.8.0 保留原本 `interfaceMode`；缺少配色欄位時自動套用「翡翠綠」。
- `salarymate_v310_state` 儲存鍵維持不變。
- 公司、薪資、派遣時薪、加班快照、請假、年終、調薪與全部試算公式未變更。
- JSON 備份會保留版面與配色偏好；匯入舊備份仍可自動升級。

## Release Gate

開發中預檢：

```bash
node tests/release-gate.mjs --allow-dirty
```

正式發布需由使用者另行下達發布指令；本次建置不會自動覆蓋線上 v3.8.0。
