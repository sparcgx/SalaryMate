# 個人薪資管理 v3.10.0｜PWA 安裝版

## 新增功能

- 加入 PWA Manifest、192／512 圖示與獨立視窗顯示模式。
- 功能選單新增「安裝到手機／電腦」。
- iPhone／iPad 顯示 Safari「加入主畫面」操作說明。
- 加入 Service Worker App Shell，曾成功開啟後可離線啟動主要介面。
- 偵測到新版時顯示「立即更新」，由使用者決定何時重新載入。
- 編輯視窗尚未關閉時阻止重新載入，避免未儲存輸入遺失。
- PWA 捷徑支援直接開啟「新增薪資紀錄」。

## 對現有使用的影響

- Schema 維持 13，沿用 `salarymate_v310_state`，不改寫既有薪資資料。
- 原有網站網址與瀏覽器使用方式保持不變；PWA 安裝是額外選項。
- 月薪、派遣時薪、加班快照、請假、年終、調薪、四種版面及六組配色全部保留。
- Service Worker 只快取公開應用程式檔案；薪資資料仍保存在裝置的瀏覽器儲存空間。
- 清除瀏覽器／網站資料或移除相關儲存仍可能刪除本機紀錄，安裝前與定期使用均建議匯出 JSON 備份。
- 不同瀏覽器或不同裝置不會自動同步資料；必要時使用 JSON 備份與還原搬移。
