# v4.3.1-web-dev.2｜高動態可見度調整

2026-09-29。承接已發布的 v4.3.1-web-dev.1，依使用者「高動態不夠明顯」回報調整同一網站。

## 改善

- 高動態背景由 20 秒、約 3% 位移，調整為 8 秒、約 13% 水平位移並提高柔色流光濃度。
- 高動態卡片白色表面透明度由 76% 不透明調至 66%，導覽由 78% 調至 68%，保留深色文字和高不透明度輸入欄位。
- 主要指標卡、試算頁首及導覽增加只作用於邊緣的流動高光；目前選中的導覽按鈕增加掃光。
- 觸控、滑鼠均有點按光波，使用被動 pointerdown，不攔截點擊或捲動。一次只保留一個光波，700ms 後清理，切換模式、失焦或進入背景也清理。
- 高動態設定選項有即時動態樣本；一般、精細的既有外觀不變，仍預設精細。
- 繼續尊重減少動態、減少透明度、高對比及背景暫停；不要求動作感測權限。
