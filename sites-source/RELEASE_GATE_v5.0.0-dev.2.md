# SalaryMate v5.0.0-dev.2 — 全介面重製開發版

日期：2026-10-02。網站入口：`/dev/v5.0.0-dev.2/`。

## 完成範圍

此版重製整套網頁操作介面，保留既有薪資、請假、補休與資料驗證核心。新版導覽、頁面、樣式和主要登記表單獨立於 v4。

| 區域 | 內容 |
| --- | --- |
| 首頁 | 最近薪資、月加班、特休餘額、年度收入、當日安排與快速登記 |
| 薪資 | 月份篩選、搜尋、明細展開、三步登記、編輯／刪除、薪資單核對、複製上月 |
| 日曆 | 月曆、每日清單、加班、單日／跨日請假、預排／確認／取消、特休額度、補休帳本 |
| 年度 | 月收入總覽、同期比較、收入組成、扣繳彙總、加班／年終／調薪試算 |
| 設定 | 公司資料、薪資規則、特休週期與額度、顯示偏好、JSON 備份還原、CSV、資料健檢、授權隱私 |
| 共用 | 桌面側欄、手機底部導覽、表單與對話框、空白狀態、錯誤提示、列印及法律說明頁 |

白底、文字導覽、細分隔線；不載入 v4 玻璃效果與裝飾資產。桌面與手機使用同一套資訊結構，進階計算與說明以展開區呈現。

## 資料與版本邊界

- 網頁本機儲存使用 `salarymate_v5_full_state`，Schema 13。
- 不自動讀寫 Stable v4 的 `salarymate_v310_state` 或 v5-dev.1 的 `salarymate_v5_worklog`。
- 支援完整 SalaryMate JSON 備份的預覽與確認還原；v5-dev.1 日曆資料格式未提供自動轉換。
- 原 Stable v4.3.2、v4.3.3-dev.1 合規版與 v5.0.0-dev.1 檔案保持原樣。
- Service Worker 與快取使用 dev.2 自身路徑和名稱；不清除其他版本快取。
- 此版為網站開發版；沒有建置、簽章或發佈 Android APK，沒有調整 Android versionCode；iOS 工作未啟動。
