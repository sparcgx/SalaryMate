# v5.0.0-dev.2-R4 — 新增公司計薪方式

2026-10-02。新增公司第一步加入月薪制／時薪制選擇。

月薪制顯示基本月薪；時薪制顯示基本時薪與每月正常工時，並即時預覽換算月薪。時薪及正常工時必須大於零，工時上限 744。建立後，公司與每月薪資快照均保留 employmentMode、baseHourlyRate、defaultRegularHours，新增薪資會帶入正確基礎。

既有公司快速編輯不更換計薪方式；時薪公司仍由完整公司設定維護，以保護既有薪資快照。

40 項操作與核心測試通過，包含月薪公司舊流程、時薪公司建立、必填驗證及薪資預設帶入。CSS 及 JavaScript 語法通過。
