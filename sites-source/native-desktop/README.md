# SalaryMate v5.1.0 正式版 · Windows / macOS

v5.1.0 新增台股與美股股票／ETF 開盤至收盤自動行情，桌面封裝 1，build 5010001。薪資與投資程式不重寫，資料 KEY `salarymate_v5_full_state`、Schema 15 維持一致。

## 安裝

- Windows 10／11 64 位元：開啟 `SalaryMate_v5.1.0_win_x64.exe`，選擇個人安裝位置。此包不要求系統管理員權限。
- macOS 13 以上 Apple Silicon（M 系列）：`SalaryMate_v5.1.0_mac_arm64.dmg`。
- Intel Mac 保留[桌面封裝 2](https://github.com/sparcgx/SalaryMate/releases/tag/v5.0.0-desktop.2)；本次優化發行只包含 Windows x64 與 Mac arm64。
- Mac 開啟 DMG，將 SalaryMate 拖到 Applications（應用程式），再從應用程式開啟。
- 尚未提供發行者簽章憑證。Windows 未有 Authenticode 簽章；Mac 只有 ad-hoc 完整性簽章，沒有 Apple Developer ID 與公證。首次安裝可能被系統阻擋；請核對下載來源與 SHA-256，不要關閉系統的整體安全保護。受管理的電腦可能需要管理員核准。

## 資料與升級

- Windows 資料：`%APPDATA%\SalaryMate`；Mac：`~/Library/Application Support/SalaryMate`。兩者都是使用者自己的本機資料。
- 網站、Android、單一 HTML 及各電腦的資料分開儲存。先在原入口匯出一般或加密備份，再到桌面版「設定 → 匯入備份」，檢查預覽後才確認匯入。
- 升級沿用相同應用程式 ID、資料目錄與儲存來源。Windows 解除安裝設定為保留 App 資料；手動刪除資料目錄仍會遺失資料。更換電腦前請匯出備份。
- 檔案匯出會先寫入暫存檔並讀回驗證，再取代你選定的檔案。取消／驗證失敗不會回報成功；驗證失敗保留原檔。
- 「自己的 Google Drive」使用 Google Drive 電腦版同步資料夾；需自行安裝並登入自己的帳戶。App 儲存完成只代表本機檔案驗證成功，雲端同步進度請看 Drive。沒有內嵌 Google 登入或自動合併資料；網站版原 Google Drive 流程保持不變。

## 離線、查詢與功能

介面、全部風格、背景、晶羽／魔法、政府辦公日曆與級距快照均包含於安裝包。重型內容仍在需要時讀取本機檔案，第一畫面不用下載網站。行情、淨值、配息與歷史匯率需要網路：桌面主程序沿用網站的公開資料查詢與驗證模組，僅傳查詢所需代號、日期與幣別；不傳公司薪資、持股數量、帳戶餘額或備份內容。更新中心可手動檢查、下載並校驗新版，備份完成後由使用者確認開啟安裝檔。

辦公日曆仍為政府機關參考，不能自動認定公司的休息日／例假或套用加班倍率。級距與日曆快照的核對日為 2026-10-16。

## 可重現建置

在既有 GitHub 開發分支執行 `.github/workflows/salarymate-desktop.yml`，Windows runner 產出 NSIS EXE，Mac runner 產出 arm64 DMG。原始碼鏡像位於 `sites-source/`。本機建置時在此目錄依序執行：

```
npm ci --ignore-scripts
npm run assets
npm test
npm run package -- --win --x64
# Mac 上分別用 --mac --arm64 或 --mac --x64
npm run verify -- x64
```

套件鎖定 Electron 44.9.0、electron-builder 26.15.3。Electron 的 Chromium／第三方授權檔由打包器保留；應用程式既有授權說明也包含於離線包。

## 桌面更新中心

「設定 → 桌面工具 → 桌面更新中心」，或上方「說明／桌面工具 → 更新中心」。

1. **檢查新版**：顯示目前正式版本、桌面封裝編號、最新正式桌面版、更新說明與上次檢查時間。只在按下檢查時連線；重新開啟時可查看標示為舊結果的快取。版本比較包含桌面封裝編號，Android／預發行不會混入。
2. **下載更新**：自動匹配 Windows x64 或 Mac arm64，選位置後顯示下載及讀回校驗進度。取消、斷線、逾時或大小／SHA-256 不符時，停止更新並保留原檔。安裝包串流寫入，驗證以 256 KiB 緩衝讀回；不整包載入記憶體。
3. **備份並安裝**：先確認並選私人位置儲存一般 JSON 備份；備份成功後重新核對安裝檔，再呼叫系統開啟並結束 SalaryMate。Windows 依精靈操作；Mac 將 App 拖到 Applications 取代舊版。取消備份或校驗失敗均不開啟安裝檔。

更新只連到此專案的公開 GitHub 發行資訊及 GitHub 素材下載主機，不上傳薪資、投資或備份內容。SHA-256 核對下載完整性，不能代替發行者簽章。現有簽章限制仍適用；不提供背景自動安裝、系統防護繞過或自動降版。

舊桌面封裝 4 尚無更新中心，需先手動安裝本次封裝 5；之後從更新中心檢查後續版本。下載狀態只在本次程式執行中保留，重開後可重新下載或自行開啟已保存的安裝檔。升級沿用既有資料位置，網站版下載入口同步指向最新安裝包。

## 桌面工具

到「設定 → 桌面工具」或視窗上方「桌面工具」選單使用。

- **自動備份**：預設關閉。先選自己的私人資料夾，再開啟；間隔可選 5／15／60 分鐘，保留 10／30／60 份。僅在程式執行期間排程，內容未變不另存重複版本；不會隨系統登入自動啟動。立即備份可手動執行。
- **備份歷史**：先驗證 JSON 與 SHA-256，再顯示原有匯入預覽。要回復完整版本，選「完整還原 → 全部取代」並核對確認。啟用自動備份時，匯入前先保存目前資料，保存失敗即停止匯入。
- **資料位置**：所選資料夾下的 `SalaryMate-Backups/<本機識別碼>/`；只輪替本安裝建立並記錄的版本。一般 JSON 包含薪資與投資資料；需要密碼保護時，使用原有手動加密備份。Drive 雲端同步完成與否，仍以使用者自己的 Drive 電腦版為準。
- **快捷登記**：桌面選單可直接開啟薪資、加班、請假、股票交易的原有表單。可選擇啟用全域快捷鍵及系統匣／選單列入口；Windows 預設 `Ctrl+Shift+M`，Mac 預設 `⌘+Shift+M`。若被占用可改另一組。保留未完成的編輯，不另開第二份資料。
- **背景常駐**：只有開啟快捷鍵功能後，關閉視窗才隱藏到背景；從系統匣／選單列「結束」完全退出。完全退出後不再執行定時備份。
- **直接輸出 PDF**：「年度 → 預覽報表 → 儲存 PDF」，或由桌面工具開啟報表。沿用目前公司範圍、年度、截止月份及原有計算，產生 A4 橫式、有頁碼的 PDF。此報表為既有薪資年度摘要；投資收入仍在投資頁查看與匯出。輸出在本機完成，不上傳私人資料。

新功能沒有增加外部套件，也沒有修改薪資、加班、假別、FIFO 公式或備份 Schema。

## 保留的效能調整

- 開窗前不再載入行情與匯率模組；首次查詢才初始化，同時查詢共用初始化結果，失敗可重試。
- 本機素材依 SHA-256 ETag 核對快取；內容未變的條件式請求回傳 304，HEAD 不讀取整份檔案。升級後內容雜湊改變就讀取新版。
- Blob／CSV／HTML 匯出直接傳送位元組，移除 Base64 轉換；IPC 仍有必要的隔離複製。一般與加密 JSON 備份格式不變。
- 寫入與 SHA-256 讀回驗證分段執行，驗證緩衝上限 256 KiB；驗證成功才取代原檔。取消、損壞、截短或變長時保留原檔。
- 移除桌面包中 3 張無引用的歷史素材，減少 3,695,404 bytes。完整來源仍保留它們；所有目前背景、晶羽、飛行／魔法及相容素材均保留。
- Mac M 系列包為原生 arm64，Windows 為原生 x64。
