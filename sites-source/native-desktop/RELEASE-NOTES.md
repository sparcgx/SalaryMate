# SalaryMate v5.3.1 正式版

強化更新套件、啟動及手動還原的穩定度。

- 版本切換成功存檔後才生效；磁碟寫入失敗不會誤認更新或還原完成，可再次嘗試。
- 重複啟動確認與套件操作依序處理，保留正確的上一版還原紀錄。
- 平常啟動不再重寫版本紀錄；無法保存還原狀態時，開啟驗證可用的程式並顯示提示，避免反覆重啟。
- 重新檢查新版時保留仍符合官方檔案的已匯入內容套件。
- 本版修正主系統載入器，v5.3.0 或更早版本需透過更新中心升級完整安裝檔一次；後續相容更新仍支援內容／差異套件。
- 薪資與投資紀錄、資料儲存位置及備份格式維持一致。

Windows x64 安裝檔尚無發行者憑證；Mac Apple Silicon 採 ad-hoc 簽署，未經 Apple 公證。程式與封裝測試不等同使用者裝置的實際安裝驗收。
