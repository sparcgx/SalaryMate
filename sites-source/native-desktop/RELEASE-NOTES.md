# SalaryMate v5.2.1 正式版

修正「深色」、「晚霧星紫」與「HD-2D」三種深色介面下，智慧分析標題、買賣觀察卡片與提示訊息白底配淺色字的問題。卡片改用主題底色，圖表線條、資料來源連結、期間選取與原創圖示選單同步提升對比；分析區在半透明場景下保留清楚底色。

保留 v5.2.0 的原創圖示、台美股票與 ETF 智慧分析、盤中行情更新、桌面更新中心及備份功能。沒有變更投資判斷規則、交易紀錄或資料格式。

Windows x64 安裝檔尚未以商業憑證簽署；Mac Apple silicon 採 ad-hoc 簽署，未經 Apple 公證。建置與封裝驗證不代表已在使用者裝置完成安裝或升級。
