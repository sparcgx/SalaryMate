SalaryMate **v5.1.0 正式版**，桌面封裝 1（build 5010001）：台股與美股的股票／ETF 在一般交易時段自動更新行情。

| 電腦 | 安裝檔 |
| --- | --- |
| Windows 10／11，64 位元 | SalaryMate_v5.1.0_win_x64.exe |
| Mac M 系列，macOS 13+ | SalaryMate_v5.1.0_mac_arm64.dmg |

在「投資」頁開啟「連動」及「自動」，並將標的價格設為自動更新：

- 台股上市／上櫃股票與 ETF：台北時間 09:00–13:30。
- 美股股票與 ETF：紐約時間 09:30–16:00，自動處理夏令時間、已知休市日及提早收盤日。
- 投資頁開啟且可見時，每 60 秒查詢正在交易的市場，收盤後補抓一次行情；背景、離線或編輯時暫停。可隨時按「更新」手動查詢。
- 畫面顯示交易狀態、來源成交時間及即時／延遲／過舊標記。60 秒是查詢頻率，並不保證來源零延遲。抓取失敗保留先前價格與時間。
- 台股盤中成交查詢獨立於收盤資料服務，收盤來源故障不再阻擋盤中價格；ETF 成交價與預估淨值分開保存。

交易日來源：[TWSE](https://www.twse.com.tw/zh/trading/holiday.html)、[NYSE](https://www.nyse.com/trade/hours-calendars)。台股每六小時嘗試更新當年度行事曆；美股內建已公布的 2026–2028 年資料。未知年份會顯示「交易日待確認」並暫停自動查價。臨時停市依來源可用行情處理，來源時間不會改成抓取時間。

保留既有薪資計算、交易成本、手動價格、備份格式、資料目錄、App ID、資料 KEY salarymate_v5_full_state 及 Schema 15。行情請求只傳公開市場與代號，不傳薪資、帳戶名稱、持有股數或交易明細。

已有 v5.0.0 桌面封裝 5 可從「設定 → 桌面工具 → 桌面更新中心」檢查、下載、校驗及備份後安裝。更早版本請手動下載。下載成功不代表安裝完成，請依系統安裝步驟操作。

Windows 尚無發行者憑證；Mac 僅 ad-hoc 簽章，尚無 Apple Developer ID／公證。SHA-256 用於檔案完整性校驗。本版不會在背景自動安裝，也不要求關閉系統防護。

驗證涵蓋交易時段與時區、休市與提早收盤、來源時間、失敗保留、分市場更新、既有桌面功能與打包內容。實際 Windows／Mac 安裝與升級、資料保留及系統操作仍須實機驗證；CI 與檔案校驗不代表這些操作已驗收。
