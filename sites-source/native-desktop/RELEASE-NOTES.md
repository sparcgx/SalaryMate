# SalaryMate v5.3.1 桌面封裝 3

修正安裝版套用差異更新時出現「更新尚未完成／操作未完成，請重試」的問題，build 5030103。

- 原因是 Electron 封裝檔的虛擬檔案識別碼，與讀取時產生的暫存檔識別碼不同，舊版將它誤判為讀取失敗。此次修正只針對已安裝封裝檔；私人備份、已下載套件與更新目錄仍保留原本的檔案識別檢查。
- 每個重用檔案仍檢查路徑、檔案類型、大小與 SHA-256。備份成功後才套用，啟動確認與失敗還原機制不變。
- 更新中心增加讀取失敗、資料備份格式及服務未就緒的具體提示，未知錯誤會顯示可用來查修的代碼。
- Windows 與 Mac 建置新增真正透過封裝程式執行的回歸驗證，涵蓋差異／完整內容套件、啟動確認、還原及隔離測試資料保留。

**升級方式：**此次更動桌面主系統中的讀檔程式，桌面封裝 1／2 需使用一次完整安裝檔。先匯出備份，再到原安裝位置更新，不必先解除安裝。更新後一般介面與行情模組仍可使用內容套件；未來主系統再變更時才需要完整安裝檔。

保留星期六預設 8 小時、小圖示、深色介面修正，以及既有薪資、加班和投資資料格式與位置。

Windows x64 使用 EXE；Mac M 系列使用 DMG。檔案經 SHA-256 完整性校驗。Windows 尚無發行者簽章；Mac 採 ad-hoc 簽署、未經 Apple 公證。封裝讀檔驗證不等同使用者裝置上的安裝精靈與畫面重啟驗收。
