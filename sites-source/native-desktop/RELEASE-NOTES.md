# SalaryMate v5.2.0 正式版

新增原創彩色向量圖示：股票、ETF、基金、債券、股息、科技與全球市場，可自動辨識或在股票編輯頁選擇。自訂圖片與原有備份資料繼續保留。

投資新增「智慧分析」分頁，取得 TWSE、TPEx、Nasdaq 歷史收盤資料，在本機計算 20／60 日均線、Wilder RSI(14)、20 日波動與 60 日最大回落。提供分批買入觀察、續抱、觀望與減碼風險評估，附判斷依據、來源與日期。

這是固定規則的技術分析，不是生成式 AI 或獲利預測；未經獲利回測驗證。使用未還原收盤價，尚未涵蓋所有公司事件；資料不足、過期、缺漏或疑似價格跳動時暫停建議。不會自動下單，也不改寫記帳交易。市場查詢僅傳公開市場與代號，持股與薪資留在本機。

保留台美股開盤至收盤每 60 秒更新、桌面更新中心、備份及 SHA-256 下載驗證。

Windows x64 安裝檔尚未以商業憑證簽署；Mac Apple silicon 採 ad-hoc 簽署，未經 Apple 公證。建置與封裝驗證不代表已在使用者裝置完成安裝或升級。
