# SalaryMate v5.3.1 桌面封裝 2

將網站的小圖示與星期六加班修正帶到 Windows 與 Mac，build 5030102。

- 主選單、投資分頁、功能按鈕、設定與下拉欄位加入一致的小圖示，保留文字標示，配合深色主題與窄版畫面。
- 星期六新增加班時預設為 8 小時；保留手動輸入的時數與既有紀錄。
- 已安裝 v5.3.1 桌面封裝 1：到「設定 → 桌面工具 → 桌面更新中心」，檢查新版並下載更新套件，備份後重新啟動套用。符合基底時使用差異套件，其他相容情況使用完整內容套件；不需重新下載 Electron 主系統。
- 新安裝或 v5.3.0 及更早版本：使用 Windows x64 EXE 或 Mac M 系列 DMG 完整安裝檔。
- 沿用原有薪資與投資資料位置、備份格式、更新驗證與失敗還原機制。

檔案下載與更新均經 SHA-256 完整性校驗。Windows 安裝檔未具發行者簽章；Mac 採 ad-hoc 簽署，未經 Apple 公證。程式與封裝驗證不等同使用者裝置的實際安裝驗收。
