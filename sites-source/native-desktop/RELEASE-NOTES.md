SalaryMate **v5.0.0 正式版**，桌面封裝 5（build 5000107）：加入 **桌面更新中心**。保留自動備份、快捷登記、PDF、全部既有薪資／投資功能與風格。

| 電腦 | 安裝檔 |
| --- | --- |
| Windows 10／11，64 位元 | `SalaryMate_v5.0.0_win_x64.exe` |
| Mac M 系列，macOS 13+ | `SalaryMate_v5.0.0_mac_arm64.dmg` |

從「設定 → 桌面工具 → 桌面更新中心」，或上方「說明 → 更新中心」使用：

- **檢查新版**：顯示目前／最新版本、桌面封裝編號、上次檢查時間與更新說明。只查正式桌面發行，不混入 Android 或預發行；啟動時不連線查更新。
- **下載與校驗**：依 Windows x64／Mac arm64 自動選安裝檔，串流下載、進度顯示、取消及 SHA-256 讀回校驗。失敗保留原檔，不回報完成。
- **備份並安裝**：確認後選私人位置保存一般 JSON 備份；成功後再核對安裝檔，呼叫系統開啟並結束 SalaryMate。取消備份或檔案遭修改，均會阻止開啟。Windows 依精靈操作；Mac 將 App 拖到 Applications 取代原程式。

封裝 4 尚無更新中心，請先手動安裝本版。下載完成不代表安裝完成；後續版本由更新中心檢查。現有資料目錄、App ID、資料 KEY、Schema 15、備份格式與計算公式保持一致；此次未新增依賴。

**隱私**：更新查詢與下載只使用此專案的公開 GitHub 發行及素材主機，不上傳私人薪資、投資或備份內容。更新前備份為一般 JSON，請選私人資料夾；原有手動加密備份仍保留。

**簽章**：Windows 尚無發行者憑證；Mac 僅有 ad-hoc 簽章，尚無 Apple Developer ID／公證。SHA-256 核對檔案完整性，不能取代發行者簽章。請依系統提示核對來源，不要關閉整體系統防護；本版不會背景自動安裝。

**程式驗證**：版本／架構／來源限制、更新下載取消／逾時／損壞阻擋、備份失敗阻擋、既有桌面功能、CSP、封裝架構與 Mac 映像完整性。詳見 CI、SHA-256 及 `verification-*.json`；合成檔案效能數字不代表開窗時間或 FPS。

**實機待驗證**：Windows／Mac 的安裝與升級交接、實際網路下載／取消、資料保留、備份還原、快捷鍵／系統匣、PDF 中文分頁與動畫。未使用瀏覽器或模擬器驗收。
