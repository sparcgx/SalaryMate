# SalaryMate v5.3.2 桌面封裝 1

股票／ETF 行情新增漲跌額，並加入版本中心，build 5030201。

- 行情依序顯示「最新價 → 漲跌額 → 漲跌幅」。上漲顯示 ▲ 與正號、下跌顯示 ▼ 與負號、平盤顯示 ＝ 0.00；台股與美股皆使用來源提供的金額，缺少資料顯示「—」，不從百分比反推。
- 設定新增「版本中心」，也能點側欄版本號開啟。列出目前使用版本、更新日期與各版重點；桌面版另顯示封裝編號並可前往桌面更新中心。
- 更新紀錄隨程式提供，離線可讀，支援繁體中文、英文及既有主題。既有薪資、投資、加班與備份格式維持相容。

**升級方式：**已安裝 v5.3.1 桌面封裝 3，可在「桌面更新中心」檢查新版、下載較小的差異更新套件，再選「備份並重新啟動套用」。此次沒有變更主系統。v5.3.1 桌面封裝 1／2 的更新程式較舊，仍需先用完整安裝檔升級一次；不必先解除安裝。

保留星期六預設 8 小時、小圖示、深色介面修正，以及桌面封裝 3 的逐檔校驗、備份後套用、啟動確認與失敗還原。

Windows x64 使用 EXE；Mac M 系列使用 DMG。檔案經 SHA-256 完整性校驗。Windows 尚無發行者簽章；Mac 採 ad-hoc 簽署、未經 Apple 公證。封裝讀檔驗證不等同使用者裝置上的安裝精靈與畫面重啟驗收。
