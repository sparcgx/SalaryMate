# SalaryMate v5.3.0 正式版

新增更新套件功能。日後一般介面、功能與台美股行情模組更新，可只下載程式內容，保留已安裝的主系統；相容時優先下載差異套件。

- 更新中心提供下載套件、匯入套件、備份並重新啟動套用、還原上一版程式。
- 套用前校驗官方檔案 SHA-256、每個內容檔案及主系統相容性，保留原有薪資與投資資料。
- 新版啟動成功才完成切換；啟動失敗或中斷時回復上一個可用版本。
- v5.2.1 或更早版本需先安裝一次本版，以取得套件載入器。未來主系統或原生功能變更時，仍需完整安裝。
- 第一個套件版本提供完整內容套件；後續相容版本由建置流程自動產生差異套件。

Windows x64 安裝檔尚無發行者憑證；Mac Apple Silicon 採 ad-hoc 簽署，未經 Apple 公證。程式與封裝測試不等同使用者裝置的實際安裝驗收。
