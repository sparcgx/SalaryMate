# SalaryMate R93：分段顯示、按需載入與安全儲存

本次接續 R92 原始碼 `99efd2999c60f89aa39d9f412d57111c8472256a`，沿用既有 Sites 專案與架構。正式版 v4.3.2 保持凍結；資料 KEY `salarymate_v5_full_state`、Schema 15、薪資／加班／請假／FIFO 計算規則及備份格式保持不變。

## 已完成

1. **交易分段顯示**：年度交易、年度股息及單檔股票全部年度紀錄，每頁最多 50 筆，最新在前。搜尋、年度、交易類型與分頁籤切換會回到首段；刪除後頁碼會收斂至有效範圍。翻頁只替換表格區域，保留對話框及橫向捲動。完整計算、搜尋與匯出仍涵蓋全部資料。最多 100 筆的批次交易預覽維持完整顯示，便於核對。
2. **FIFO 明細按展開建立**：閉合時只產生成本摘要。首次展開讀取該次畫面的已計算事件快照，沿用原本的 lot 順序、數值與格式；重新開啟同一列不重建。未保存批次、不同表區及過期 toggle 各自隔離，不用目前模型覆蓋原畫面快照。
3. **網站說明按需載入**：首屏不載入法律資料；使用者開啟授權／隱私視窗時才載入版本化同源模組。包含載入狀態、去重、20 秒超時、失敗重試與關閉／替換後拒收晚到畫面結果。載入途中切換語言，完成時使用目前語言。移除 script 不能保證網路下載立即停止，本次保證回呼清理與不覆寫其他視窗。
4. **使用後保留離線快取**：法律模組與法律 HTML 不再安裝預抓；版本化模組首次需求後 cache-first。首次頁面尚未受新 SW 控制時，成功載入會在 ready／新 controller 接手時通知快取。升版只遷移精確目前版本的 OPTIONAL URL，不能把舊版法律內容當成新版。
5. **減少完整複製與重複保存**：專用純 UI 提交只允許 18 個既有 scalar 偏好欄位，以小型 metadata 快照回復；財務資料修改及任意 mutation callback 仍完整複製並回復。相同且已保存的 UI 值略過序列化、寫入與備份通知，但仍檢查跨分頁衝突。底層相同字串也在衝突檢查後略過寫入；明確 reset 保留強制寫入。
6. **成功邊界與備份**：本機寫入成功後，狀態顯示或 Drive 通知例外不再觸發錯誤回復。儲存失敗時仍回復原資料、偏好及欄位存在性，釋放操作鎖；年終草稿只在設定保存成功後清除。一般／加密備份移除多餘的整份 clone，完整 JSON 內容保留；加密仍在第一個 await 前形成獨立 bytes 快照。

儲存測試使用 10,000 筆虛構薪資紀錄：UI 提交完整 clone 0 次，財務提交仍 1 次；重複 UI 值的序列化、寫入及備份通知均 0 次。真正變更後仍保存一份完整狀態，沒有改為部分資料保存。

上述 bytes 是產生的內容或資源檔案量，不是實測記憶體、下載總量、開啟秒數或 FPS。沒有用虛構資料的數字推論手機流暢度。

## 驗證與完整離線版

合併既有回歸與本次新增案例 **128/128 PASS，0 FAIL，0 SKIP**。涵蓋 0／1／49／50／51／101／10,000 筆逐頁順序、不漏列、不重複、股息欄一致、FIFO 原快照與小數格式、未保存批次、儲存額度不足、跨分頁衝突、失敗回復、通知例外、備份 JSON 相容、實際加解密、延後載入重試、晚到結果與快取遷移。

16 個 JavaScript 語法、CSS 解析、單一 HTML 16 個 script 精確 CSP 雜湊通過；56 個凍結／非開發版檔案與 R92 逐位元一致。沒有使用虛擬瀏覽器、DOM 模擬器或私人資料。

完整離線單一 HTML 為 **31,799,706 bytes**，仍內嵌全部既有背景、晶羽飛行與魔法素材，以及完整法律模組。法律模組逐位元核對；離線內容直接從記憶體開啟，不建立外部 script。行情與自己的 Google Drive 仍依既有流程需要連線。

## 後續限制與實機待驗證

- 交易計算仍涵蓋整本交易，分段降低的是畫面建立成本；大型匯入、完整匯出與同步狀態序列化仍隨資料量增加。
- 表區快照最多保留四個固定 context；關閉明細後會暫留該次計算結果直到被覆蓋。若再做釋放，必須區分真正關閉與頁面暫時隱藏，避免破壞回到畫面後的 FIFO。
- 網站的其他模組仍沿用既有啟動依賴；本次按需載入範圍是完整法律說明。完整離線版保留全部內容，檔案大小仍約 31.8 MB。
- 手機／桌面的首次開啟、重開快取、每頁翻閱、橫向捲動、明細展開、晶羽首次飛出與魔法動畫仍待實機驗收；沒有實測 FPS 通過宣稱。
