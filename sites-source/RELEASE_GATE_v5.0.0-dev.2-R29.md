# R29 — 投資清單加寬及縮短列高

- 持股、觀察清單、交易紀錄、實收股息採共用 stock-ledger。
- 股票欄至少 220px（手機 210px）；行情欄至少 280px（手機 260px）；名稱及行情資訊不任意斷行。
- 每格上下內距縮為 10px（手機 8px），保留字級與全部欄位、橫向滑動。
- 交易長備註仍可換行；FIFO 展開及操作保留，手機操作按鈕至少 44px。
- 行情來源時間只有與價格日期完全相同時合併顯示，有具體時間仍完整保留。

檢查：四種清單 JSDOM 渲染、欄位寬度及不換行樣式、日期合併與來源時間保留、投資資料前後不變、CSS 解析及 JavaScript 語法均通過。未使用虛擬瀏覽器；實機列數與視覺待使用者確認。
