# R98：華麗風格按需下載與設備快取

基準 R97 `8bd220963ae78f6b3e0ea6d5f76e51a392e7f922`。沿用原網站、模組、資料與凍結正式版。

## 行為

選單內八種華麗風格（秋天手帳水彩、繽紛手繪、奶油暖陽、晚霧星紫、彩鉛日常、清爽工作室、馬卡龍華麗、奇幻 HD-2D 華麗）選用後才取得樣式包。只有奇幻 HD-2D 另下載晶羽飛行程式；飛行圖片與魔法圖片仍沿用互動時分階段載入。

下載完成才保存及套用新選擇；失敗、20 秒逾時或無效飛行模組保留目前風格並可重試。快速切換時較早的完成結果不會蓋掉最後選擇。重開且已有華麗偏好時先用一般樣式呈現可操作內容，準備完成才恢復原風格；失敗不覆寫保存的偏好。

一般風格只載入 styles-core.css 與縮小的 startup.js；華麗風格包使用原完整 styles.css，以保持所有樣式、選擇器優先度及原有順序。套用完整樣式時停用 core，回到一般風格時重新啟用 core，避免兩份樣式互相覆蓋。風格選單尚未選用時縮圖保留輕量框線配色，不先讀取大型場景圖或晶羽圖片。

網站版透過版本化 HTTP 快取及 Service Worker Cache Storage 留存在目前設備／瀏覽器。套件不列入強制離線安裝；第一次選用後保留，下一次可離線讀取。首次頁面早於新 worker 接管時，會補存所選樣式包；更新啟用時保留已由舊 worker 取得的相同新版本套件，不拿過時版本混用。瀏覽器仍可能清除快取。

完整單一 HTML 繼續內嵌全部原始樣式、晶羽程式、背景與素材，不依賴網站下載套件。資料 KEY、Schema 15、薪資／股票計算與自己的 Google Drive 不變。沒有新增第三方服務或動畫依賴。
