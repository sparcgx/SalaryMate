# SalaryMate v3.6.0｜薪資成長與年終試算

## 功能契約

- 「時薪價值」改為「薪資試算」，並分成「加班費試算／年終試算／加薪紀錄」三個頁籤。
- 時間價值分析保留為選用進階區塊，預設收合，不影響既有資料與試算設定。
- 年終試算支援固定月數、績效級距、自訂基數、年資比例、額外調整與預扣稅門檻／稅率。
- 每年加薪紀錄以生效日保存完整固定薪資快照，供之後新增的薪資明細、請假扣薪與年終試算套用。
- 既有薪資明細不因公司設定或調薪紀錄回溯改寫。
- 每日加班時薪採「每筆獨立快照」：公司日後加薪或減薪都不會改動舊紀錄。
- 每日加班時薪輸入與列表統一保留三位小數，例如 `100.111`；計算時使用該筆保存值。

## 資料遷移

- Schema 升級為 10。
- 新增 `salaryAdjustments` 與 `yearEndEstimates` 集合。
- 新增薪資試算頁籤、進階時間價值展開狀態及公司選擇偏好。
- 舊加班紀錄沿用原本保存的 `hourlyRate`，正規化至三位小數，不重新連結公司薪資。
- JSON 備份、還原、清除與資料健檢均涵蓋年終及調薪資料。

## UI 與回歸結果

- 手機 390 × 844、平板 820 × 1180、桌機 1366 × 900 均無應用頁面橫向溢出。
- 手機右上資料選單所有動作都在可點擊範圍內。
- 公司設定固定儲存列在手機上保持可見，已實際驗證可成功儲存。
- 桌面版每月推估出勤率不會顯示內部垂直捲軸。
- 裝置預覽框採 content-box，內容尺寸與標示一致。
