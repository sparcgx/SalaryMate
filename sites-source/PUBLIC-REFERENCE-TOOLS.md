# v5.0.0 正式版：公開資料工具

2026-10-16 加入辦公日曆 → 勞保／健保級距核對 → 歷史匯率。沿用原 Sites 專案、資料 KEY 與 Schema 15。

- 工作日曆「辦公日曆」及設定入口：2026、2027 年官方完整日曆快照，各 365 天。按月顯示，放假／上班文字與顏色並用，不設定公司日別或加班倍率。
- 設定「勞保／健保級距核對」：2026 年勞保 97 列、4 種身分，健保 58 列。依有效日期、完整申報月薪資查表，可與手填目前投保額核對。投保薪資不等於自負保費，不處理健保特殊身分最低額。未收錄年度明確拒絕，不猜測新級距。
- 投資行情操作列及設定「歷史匯率」：12 個幣別，1999 年起指定日期參考價（實際可用日期依來源），顯示查詢日及實際參考日。Frankfurter 預設混合中間價，非銀行成交匯率。只傳日期與幣別，私人金額留在本機。
- 年表為已核對、隨發布更新的官方快照，並非每次開頁即時重新抓取。原始 CSV／JSON 與 SHA-256 可追溯；更新來源後須重新驗證，再執行 build-public-reference.mjs。
- 網站只在開啟工具時載入 reference-data.js、reference-tools.js，SW 點用後快取。完整 HTML 內嵌兩模組；日曆與級距離線可查。歷史 FX 首次需連線，僅存公開查詢結果最多 60 筆。斷線保留快取並明示狀態，失敗不改交易或薪資。
- API 限定幣別、日期、方法、來源、請求頻率、併發、逾時與回傳格式。後端快取 100 筆／24 小時。沒有新依賴或新增首屏公開資料請求。
- 網站素材版本標記 5.0.0-reference1；對外名稱仍 v5.0.0 正式版。既有 Android APK 未在本次重建。

## 驗證限制

程式測試與實機驗證分開。不得以 Node VM、模擬回傳或原始資料下載成功宣稱實機視覺／FPS 或 Sites 上游查詢成功。舊 v5-stocks 測試依賴未提供的 JSDOM，本次不安裝或執行該環境；股票核心 FIFO／費稅／歷史與現價匯率公式由既有 R95 純 VM 測試核對。
