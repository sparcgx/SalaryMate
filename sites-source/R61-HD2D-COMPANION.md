# R61 — Jingyu / 晶羽 HD-2D companion

The existing fantasy HD-2D theme gains an original owl companion in its home
heading, page headings, the first empty state on other pages, and operation
notices. The appearance chooser shows the mascot in the HD-2D preview. It is
decorative, never intercepts taps and does not add a new workflow or control.

The character occupies a reserved grid column, with a smaller size on mobile
and compact layouts. Financial values, controls and table cells are not
overlaid. Other themes suppress the companion. The five fantasy backgrounds
retain their scenes and give the mascot a matching ambient light color.
Dynamic modes add a gentle hover; frosted and translucent modes are static.
Reduce Motion disables the new animations. Print views hide the illustration.

The original PNG is served by the existing Site, cached with the PWA shell,
and embedded directly in the single HTML edition. There is no image service
at runtime, no data upload and no new script or external asset dependency.
Schema 15, salarymate_v5_full_state, calculations, backup and Google Drive
flows remain unchanged. Frozen v4.3.2 files are not modified.
