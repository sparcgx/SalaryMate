# R76 — 晶羽風系施法攻擊姿勢

接續 R75 原專案，保留飛行、近遠縮放、風系效果、介面與資料流程。

## 已完成

- 新增六個實際繪製姿勢：風刃蓄力、向前揮翼出招、收勢；龍捲風抬翼蓄力、雙翼高舉施法、收勢。
- 風刃提前 420ms 蓄力；龍捲風提前 560ms 蓄力。出招姿勢提前 64ms 交接，在魔法開始出現時已完成姿勢切換。
- 施法朝左或右依當下飛行方向決定，整段施法固定朝向；風刃沿出招方向發射。左向施法使用同一素材鏡像，並非新增 3D 模型或八方向攻擊模型。
- 保留 R75 最多兩姿態、64ms 短交接與單一動畫迴圈。小幅蓄力抬身與出招後座位移，收勢後回到既有方向飛行。
- 施法圖使用兩個既有姿態層的實際圖片節點解碼，不阻擋起飛。若圖像延遲或失敗，該次不切入攻擊姿勢；風系效果與一般飛行仍可運作。解碼完成不得在已開始的施法途中突然插入新姿勢。
- 保留再次點擊、Escape、捲動、縮放、切頁、對話框、離開頁面與減少動態設定的取消清理。
- Schema 15、資料 KEY、備份與 Google Drive、凍結 v4.3.2 均未變。

## 素材與對齊

- 內建 imagegen 編輯模式，一次產生，無 CLI、無程式修改 PNG 像素。
- 正式素材：`dist/dev/v5.0.0-dev.2/art/jingyu-cast-r76.png`，1536×1024 RGBA、六個姿勢。
- 精確提示及原始路徑：`R76-CAST-ASSET-PROMPT.json`。
- 原圖未完全符合等格與固定頭部要求，執行時使用量測裁切、頭部對齊，以及兩個 CSS 裁切多邊形避開相鄰姿勢。
- `R76-CAST-ASSET-MEASUREMENTS.json`：以原圖 alpha > 16 的六個主要連通區核對，六姿勢皆無遺漏角色像素、無相鄰角色混入；對齊後角色邊界均在顯示框內。極低 alpha 的邊緣仍待實機視覺驗收。

## 程式驗證

- 原生 Node VM 回歸 19/19 PASS，包含既有 16 項，以及攻擊三階段、特效時序、左右朝向、相容顯示、慢載入/失敗/取消與減少動態。
- 30/60/120 Hz 模擬均通過攻擊階段與最多兩層姿態檢查；這不是實測 FPS。
