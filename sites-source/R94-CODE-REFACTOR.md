## 本次整理

- **外觀設定共用流程**：介面風格、背景效果、HD-2D 背景、水彩背景與重點色，共用 `setVisualChoice` 處理保存、失敗還原、重繪、捲動位置、焦點及成功提示。字體密度保留專用流程，維持原控制項與觸控捲動位置。
- **股票明細拆分職責**：`eventTable` 負責組合輸出；分頁與事件快照集中在 `prepareEventFrame`，欄位、股息欄、數量、單列及分頁按鈕各有小型函式。R93 每頁 50 筆、最新在前、展開才建立 FIFO 明細及過期事件防護均保留。
- **離線圖片打包集中管理**：新增建置階段的 `scripts/lib/portable-artwork.mjs`，以一份清單管理晶羽、飛行及魔法的五組宣告，共用讀取、Base64 內嵌與宣告檢查。網站端沒有增加模組或依賴；背景與完整法律說明繼續保留於離線版。

- 既有 128 項回歸加上 9 項重構比較，共 **137/137 PASS，0 FAIL，0 SKIP**。

- 0／1／49／50／51／101 筆混合交易與純股息資料，逐頁、有／無操作按鈕、分頁／完整批次模式，產生的 HTML 與 R93 逐位元一致；分頁狀態與可展開的賣出快照 ID 一致。
