# v5.0.0-dev.2-R2 — 動態霧面玻璃

2026-10-02。原測試網址更新，資料處理與儲存保持不變。

導覽、首頁區塊、薪資、月曆、年度、設定與對話框採用霧面半透明材質。冷白背景有兩層緩慢流動的柔光；手機底部使用浮動磨砂導覽列。主要按鈕保留深色實心，表單使用較高不透明度。

支援 Safari 的 -webkit-backdrop-filter；無濾鏡能力時使用實色背景。減少動態偏好會停用背景動畫與互動位移；減少透明度偏好改用實色。列印不包含背景效果。

驗證：CSS 解析、入口與快取資產、JavaScript 語法及既有 38 項操作／資料測試。未做真實手機排版、觸控或效能驗證；當前 Sites 指定瀏覽器能力不可用。未建置 APK。
