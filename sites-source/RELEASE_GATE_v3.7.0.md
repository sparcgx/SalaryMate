# 個人薪資管理 v3.7.0｜派遣時薪制

## 功能範圍

- 任職公司新增「月薪制／派遣（時薪）」計薪方式。
- 派遣公司可設定最多小數後三碼的基本時薪，以及每月預設正常工時。
- 新增派遣薪資時，以「基本時薪 × 本月正常工時」換算底薪；時薪、正常工時與換算結果會一併保存為月份快照。
- 伙食津貼、職務加給與自訂固定加項沿用既有規則，繼續影響時薪分析、請假扣薪與加班費試算工作台。
- 派遣公司的新每日加班紀錄會建議帶入當時基本時薪，儲存後仍是獨立快照；公司日後加減薪不會回溯修改。
- 加薪紀錄與年終試算支援派遣時薪換算，既有月薪制流程維持不變。
- 薪資 CSV 增加計薪方式、基本時薪與正常工時欄位；JSON 備份完整保留新欄位。

## 資料相容性

- Schema 由 10 升級為 11。
- 舊公司與舊薪資紀錄自動補為「月薪制」，不改寫既有金額。
- `salarymate_v310_state` 儲存鍵維持不變，避免現有瀏覽器資料中斷。
- 派遣薪資與調薪資料缺少時薪／正常工時時，資料健檢會列為錯誤。
