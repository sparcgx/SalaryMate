# SalaryMate v3.5.0｜固定加給與時薪基礎整合

## 功能契約

- 公司設定新增「職務加給」與多筆「固定加項」。
- 新增薪資紀錄時，自動帶入該公司的本薪、伙食津貼、職務加給與固定加項。
- 薪資表單中的自訂加項可個別勾選「計入時薪」；公司固定加項預設勾選。
- 名義時薪、加班基準時薪與請假扣薪採相同固定薪資基礎：

  `本薪 + 伙食津貼 + 職務加給 + 勾選計入時薪的自訂加項`

- 加班費、獎金與未勾選的臨時加項仍計入應發薪資，但不列入固定時薪基礎。
- 公司預設值只自動套用於新紀錄或切換公司時；既有薪資紀錄維持當時快照，避免歷史金額被公司設定變更回溯覆寫。

## 資料遷移

- Schema 升級為 9。
- 舊公司自動補上 `positionAllowance: 0` 與 `fixedEarnings: []`。
- 舊薪資自動補上 `positionAllowance: 0`。
- 舊自訂加項名稱若包含「全勤、職務、加級、職位」，首次升級時延續既有試算語意並標記為計入時薪；之後使用者可在薪資表單取消勾選。

## Release Gate

開發中預檢：

```bash
node tests/release-gate.mjs --allow-dirty
```

封存候選版後正式檢查：

```bash
node tests/release-gate.mjs
```

只有 9 項 Gate 全數通過並顯示 `RELEASE GATE: PASS` 才可發布。此 Gate 不會自行部署正式網站。
