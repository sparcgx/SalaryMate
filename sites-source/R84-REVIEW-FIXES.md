# R84 — 三項檢查與改善

基底為同一 Sites 專案的 R83，來源提交 `65984cc49761c8eb8837a75af037d5524438dded`。開發版版本改為 `v5.0.0-dev.2-R84`。

## 問題與修正

| R83 可重現問題 | R84 改善 |
| --- | --- |
| 寬表格橫向捲至右側後，切換收藏、篩選或行情重新渲染會重建節點，捲動位置回到 0。 | 同一投資分頁依表格識別保留橫向及縱向捲動位置；切換分頁仍使用新頁起點，並同步既有捲軸控制。 |
| 預計配息自動／手動查詢未完整檢查離線及背景狀態，切頁也未中止查詢；過期回覆仍可能進入後續批次與儲存。 | 加入啟動條件、AbortSignal、請求序號及切頁／隱藏／離線／離開頁面的取消處理；恢復可見或連線後重新排程。已取消的請求不建立 HTTP 或逾時計時器。編輯對話框中收到的有效結果延後合併，保留當時最新的手動調整。 |
| 持股配置在寬度 1180px 以下被舊樣式直接隱藏，小螢幕無法查看。 | 在手機與較窄螢幕顯示於持股表格下方；保留 R83 的寬螢幕配置與列印規則。 |

## 程式驗證

- 新增六項原生 Node 物件／VM／CSS 檢查，修正前六項失敗，修正後全部通過。
- 配息檢查涵蓋隱藏、離線、切換投資分頁、離開投資頁、過期回覆、重新開始、編輯期間延後合併與預先取消；公告不會自動變成實收收入，原交易與手動計息股數保留。
- 合併既有股票欄位、更新按鈕、快取、背景與晶羽動畫回歸，共 54/54 PASS。
- 使用 `node --test tests/v5-r84-review.test.mjs tests/v5-r82-holdings.test.mjs tests/v5-r80-cache.test.mjs tests/v5-r79-backgrounds.test.mjs tests/v5-r70-flight.test.mjs`。
- 沒有使用虛擬瀏覽器；程式與 CSS 規則檢查不等於手機視覺驗收或實測 FPS。

## 範圍
