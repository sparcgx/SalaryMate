# v5.0.0 正式版：工作日曆整合辦公日曆

2026-10-18 使用者確認預覽後更新原 Sites、GitHub 開發鏡像、GitHub Pages 與既有正式單一網頁版。對外名稱仍為 v5.0.0 正式版。

- 工作日曆日期格增加政府「休／班」標示，與原加班／請假紀錄共存；提供顯示開關。日期明細顯示完整官方備註、核對日期及來源。
- 2026、2027 年沿用已核對的官方快照。未收錄年度或日期明示無資料，不依星期猜測。載入中與載入失敗分別顯示，可重試。
- 政府辦公日曆只作參考，不改公司班表、日別、加班倍率、請假時數、已存薪資或交易。公司實際出勤安排仍須另行核對。
- 網站在使用工作日曆時才載入 reference-data.js；與公開資料工具共用載入請求及已驗證快照。只為顯示而建立日期索引，不完整複製私人資料。完整 HTML 內嵌資料，離線可查。
- 手機格內保留短標示，完整名稱移到日期明細；樣式沿用既有介面顏色變數。顏色及文字並用，不依顏色單獨辨識。
- 資料 KEY salarymate_v5_full_state、Schema 15 均保留。正式 HTML 不含示範資料或預覽記憶體儲存替代碼。獨立預覽檔保留虛構資料及記憶體模式，與正式版分開。
- 網站素材標記 5.0.0-calendar1，避免舊不可變快取。保留全部既有功能及 v4.3.2 凍結內容。既有 Android APK 本次未重建。

程式驗證：34 項選定測試通過（包含整合預覽、官方資料契約、既有 R95 公式／保存回復、正式發布與 APK 下載路由）；JavaScript 語法、完整 HTML 的 19 個 script／精確 CSP 雜湊及正式資料契約核對。56 個凍結網站檔案逐位元組未變。

待驗證：手機與桌面實際可讀性、主題畫面、操作觀感與離線重新開啟；不宣稱實測 FPS 或實機通過。未使用瀏覽器、Playwright 或 JSDOM。
