# 個人薪資管理 v3.9.1｜首頁到職年資

## 功能調整

- 首頁第四張指標卡由「副業／接案收入」改為「到職年資」。
- 顯示格式為「X 年 Y 天」，以完整周年數加周年後經過天數計算。
- 選擇單一公司時使用該公司的到職日；顯示全部公司時優先使用現任公司。
- 卡片下方同步顯示公司名稱與第一天上班日。
- 未設定到職日顯示設定提醒；到職日為未來日期時顯示「尚未到職」。

## 相容性

- Schema 維持 13，不新增或改寫薪資資料欄位。
- 沿用公司既有的 `employmentStartDate`，公司、薪資、派遣時薪、加班快照、請假、年終與調薪公式均未變更。
- 副業收入欄位、薪資明細、年度加總與備份匯出功能仍完整保留；僅替換首頁指標卡。
- v3.9.0 的四種版面、六組配色與手機滑動導覽全部保留。

## Release Gate

開發中預檢：

```bash
node tests/release-gate.mjs --allow-dirty
```

正式發布需由使用者另行下達發布指令；本次建置不會自動覆蓋線上 v3.9.0。
