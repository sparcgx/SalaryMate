# R79：背景圖片按使用情境載入

延續已發布 R78，不重建網站或架構。本次只處理背景圖片載入方式，保留奇幻 HD-2D 五種背景、華麗馬卡龍背景、設定預覽、晶羽飛行與十種魔法。

## 已完成

- 將共用 CSS 內六個 WebP data URL 原樣解出為獨立檔案，檔案位元組、畫質、尺寸、場景選擇器及原有構圖均不變。
- 一般頁面僅由目前使用的背景 CSS 規則發出圖片請求。非圖片風格不需載入場景圖片；設定中的場景與風格預覽在實際顯示時才需要其圖片。
- 新背景不加入 Service Worker 的全量預載清單。已使用的背景保存在獨立快取；同一場景重訪或離線重開時可直接使用，同時請求會合併。
- 首次頁面可能在 Service Worker 接管前載入背景，因此註冊完成後僅通知快取目前場景。六個固定版本檔案具 immutable HTTP 快取，不須再下載其他場景。
- 新場景第一次使用仍須連線；已快取的場景可離線重訪。尚未載入場景在離線時保留既有底色，恢復連線後可重試。帳務與介面操作不依賴圖片載入成功。
- 單一網頁版及目前採該檔發布的 GitHub Pages 仍將全部場景嵌回，保留完整離線背景切換。此版本的整體 HTML 容量不會因分離網站 CSS 而大幅下降。
- 其他資源的快取策略、薪資與投資資料、Schema 15、備份與自己的 Google Drive 流程不變。
