# SalaryMate v4.3.2-dev.2 — 複製上月薪資與套用前預覽

## 範圍
- 以目前公司最新月份的下一月作為預設目標，可於預覽選擇其他目標月份；來源固定為該公司的目標前一月。跨年可用。
- 預覽逐項列出上月與本月帶入金額。保留本薪、固定津貼、勞健保、自提及公司固定自訂加項。加班、獎金、預扣稅、其他扣除、副業、非固定加項、所有自訂扣項（含請假連動）都清零或移除，供本月重新確認。時薪與正常工時沿用，於建立表單確認。
- 入帳日重新計算；新紀錄核對狀態為未核對。來源不存在、多筆或目標月份已存在時阻止套用。
- 預覽與套用到新增表單不會寫入資料；使用者完成新增薪資流程後才儲存。來源變更時必須重新預覽。

## 實機驗收（待使用者）
1. 各月薪資明細 → 複製上月薪資，查看公司、來源與目標月份。
2. 確認每項上月／本月數字、變動項目清零與請假扣款移除；取消不新增資料。
3. 選已存在月份，確認無法套用；切換跨年月份或沒有上月資料，確認提示。
4. 套用後於新增表單編輯本月金額；儲存後新月份的月結核對應為未核對，上月原資料保持不變。
