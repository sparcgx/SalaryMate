# v5.0.0 正式版

以 R101 功能為基礎統一正式名稱；不是重新建立專案。

- 公開首頁與 /v5.0.0/ 導向既有 v5 入口，保留同源、既有網址、資料 KEY salarymate_v5_full_state、Schema 15。
- 網站標題、安裝名稱、側欄、頁尾、設定及單一網頁版統一 v5.0.0 正式版；HTML 檔名 v5.0.0正式版.html。
- 網站的 5.0.0-formal1 素材標記避免重用先前不可變快取；對外版本仍為 5.0.0。
- Sites 的 v4.3.2 原始靜態檔案不修改；公開根路由由 Worker 導向 v5。
- Pages 根入口升為正式版導引，原完整 Pages 樹保留在 archive/v4.3.2/；main、stable/v4.3.2-web、freeze/v4.3.2-web 不修改。
- Android 使用原 R101 已發布 APK，僅替換版本與顯示名稱，沿用 app ID、資料、原生程式、套件內容與簽章；versionName 5.0.0，versionCode 5000102。
- Android 原有功能與限制皆保留；正式名稱不代表實機流暢度、FPS 或全部驗收通過。
- Android 公開下載頁由 Pages 提供；Sites 串流輸出完整 APK，Pages 保存三段公開位元組；使用者直接取得 APK，不需合併或解壓縮，不使用有期限附件連結。

程式驗證：9 項發布與下載測試、18 個網站 JS、17 個單檔 script/CSP、56 個凍結網站檔案逐位元組檢查通過。Android 原簽章、版本、名稱、556 個未變更封裝項目、全部資產雜湊及 16KB ZIP 對齊通過。

實機待驗證：Android 覆蓋安裝、資料保留、備份流程與視覺流暢度。

重現 Android：設定 ANDROID_HOME 及 SALARYMATE_SIGNING_CONFIG（私人路徑），執行 python3 scripts/promote-r101-android.py 原R101.apk 輸出.apk。簽章憑證與密碼不得提交。
