# R77 — 晶羽攻擊螢幕與衝擊震動

接續 R76，沿用既有風刃、龍捲風與六個施法姿勢；沒有新增素材或動畫依賴。

## 已完成

- 魔法由晶羽出招位置飛往螢幕中央附近，隨接近快速放大，形成迎面攻擊。
- 三道風刃在發射後約 420/495/570ms 依序命中；龍捲風在約 980ms 命中。
- 風刃每次衝擊約 540ms、龍捲風約 780ms，使用多頻位移與快速衰減；畫面水平位移上限約 34px、垂直約 21px，依視窗大小調整。
- 頁面內容、主選單、頂部列、背景裝飾及晶羽同步視覺震動，加入淡色邊緣衝擊與擴散圓環。
- 不搬動 DOM、不對 body 或 workspace 根容器套用 transform，保留選單原有固定定位；效果層不攔截操作。
- 延用單一 requestAnimationFrame 與實際經過時間。圖片載入失敗不震動；停頓後跳過的命中不補播。
- 點擊其他操作、再次點晶羽、Escape、捲動、縮放、切頁、對話框、離開頁面及動態偏好變更時立即停止，復原暫時樣式。
- 減少動態模式停用飛行、攻擊與震動，CSS 亦提供即時停止保障。
- 保留短姿勢交接、飛行近遠縮放、全部薪資/投資功能、資料 KEY、Schema 15、備份及 Google Drive。

## 程式驗證

- 原生 Node VM：22/22 PASS；未使用瀏覽器或 DOM 引擎。
- 螢幕攻擊與震動於 30/60/120 Hz、手機/橫向/桌面/小視窗模擬通過；位移受限、衝擊前不震動、兩次攻擊間回穩。
- 9 種中斷情境、原有樣式及 priority 復原、減少動態、圖片失敗與停頓後不補播通過。
- JavaScript 語法、差異、網站與單一 HTML 建置通過；16 個 script 精確 CSP 雜湊與八張內嵌圖片逐位元組核對通過。
- 凍結正式版、股票操作程式與既有素材未變；未修改 GitHub 正式治理分支。

## 實機待驗證

手機/桌面震動強度、命中視覺時序、選單位置與流暢度。程式模擬不是實測 FPS，尚未宣稱實機視覺驗收通過。
