# R83：股票清單統一、單一更新入口與寬螢幕

接續 R82，保留原 Sites 專案、全部風格與既有功能。

## 已完成

- 股票清單與持股總覽共用九欄：股票 → 分類 → 股數／剩餘均價 → 行情 → 持有成本 TWD → 市值 TWD → 未實現損益 TWD → 帳戶 → 操作。
- 股票清單保留全部標的，包括未持有／已出清股票；收藏、搜尋、分類／交易所篩選、收藏優先／代號／漲幅排序，以及買入／編輯／刪除操作不變。使用既有 FIFO 模型的股數與金額，不另寫計算。
- 上市／ETF 等標籤獨立放在分類欄，帳戶移至損益之後；行情來源時間緊接股價，與 R82 持股總覽一致。圖示、代碼與名稱層次不變。
- 移除「選項」內重複的行情更新，保留控制列上單一常駐「更新」。六個投資分頁一致，手機不用展開選項即可更新；選項仍有新增、交易與批次。
- 1181px 以上解除工作區及主內容的固定寬度上限，左右留白隨螢幕自動調整。持股表格優先使用寬度；投資區可用寬度達 128rem 才把持股配置放回右側，其餘桌面放在下方。原手機配置與表格橫向捲動保留。
- 使用純 CSS 容器查詢，不支援時保留單欄。沒有新增 resize 迴圈、動畫、圖片或套件；列印規則不變。
