# R99：首屏直接顯示與快取優先重開

接續 R98，僅調整現有 v5.0.0-dev.2 開發版的啟動流程。正式版 v4.3.2 保持凍結；資料 KEY、Schema 15、薪資與投資公式、備份和使用者自己的 Google Drive 流程維持原狀。

## 修改

- 入口 HTML 內嵌 3,013 bytes 的首屏樣式。收到 HTML 後，可先顯示標題、功能名稱及載入狀態，不必等外部 CSS、JavaScript 或圖片下載完成。初始畫面不填入假的薪資、投資金額或保存狀態。
- 共用 CSS 使用非阻擋的初始載入；啟動程式啟用正式樣式。應用程式初始化完成才解除入口操作區的 inert，正式樣式可用才移除首屏樣式範圍。樣式失敗時保留基本可讀畫面，並提示重新整理。
- 已安裝 Service Worker 的開發版入口優先使用設備快取，網路更新在背景進行。背景更新只替換相同版本的入口，避免新版 HTML 與尚未快取的程式混用。首次未有快取或快取不可用時繼續使用網路。
- 保留 R98 選用後才下載的風格資料包、按需背景與素材快取。完整單一 HTML 仍包含全部樣式、程式和素材，供離線使用。

## 程式驗證

- 既有回歸與新增首屏／快取測試：315/315 PASS。
- 新增驗證涵蓋：不等待網路的快取入口、同版本背景刷新、不同版本隔離、首次網路回退、快取失敗、離線重開、正式樣式與初始化完成順序、樣式失敗和完整離線版。
- 18 個 JavaScript 檔案語法、CSS 解析、單一 HTML 的 16 個 script 與 CSP 精確雜湊、差異檢查通過。
- 56 個凍結發行檔案與 R98 逐檔比對一致。
- 網站入口 8,263 bytes；完整網站啟動程式仍須下載與執行後，使用者資料才會呈現。首屏是載入畫面，並不代表資料已經讀取完成。

## 實機待驗證與限制

未使用虛擬瀏覽器，未進行手機或桌面實機視覺驗收，也沒有實測 FPS、FCP 或開啟秒數。首次從未快取的連線仍受 DNS、TLS、伺服器及使用者網路影響；程式改動不能保證收到 HTML 前就有網站畫面。設備快取可能因瀏覽器清理、容量限制或隱私模式而失效。

現有使用者需先取得此版本並完成新的 Service Worker 安裝，之後重開才會採用新的快取優先入口。更新不強制重新整理正在編輯的頁面。
