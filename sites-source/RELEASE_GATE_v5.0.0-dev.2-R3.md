# v5.0.0-dev.2-R3 — 顯示模式差異修正

2026-10-02。更新原測試網址。

根因：舊大字模式只改 body 字級，頁面多數字級用 rem，沒有隨 body 放大；緊湊只縮少量列間距。

修正：把偏好同步到 html，根字級標準 100%、緊湊 87.5%、大字 125%。模式同時改動內容區、紀錄列、表單、按鈕與月曆高度。手機緊湊輸入仍維持至少 16px，避免 Safari 聚焦放大。選項有三種實際大小的範例與使用中狀態。

38 項既有操作與資料測試通過；補充 DOM／CSS 檢查驗證三種模式計算根字級分別為 14、16、20px（預設 16px 環境），設定及重載持續保留。CSS 解析通過。未進行真實手機視覺排版驗證。

動態霧面玻璃保留，資料儲存與計算核心未更動。
