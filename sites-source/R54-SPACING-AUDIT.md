# R54：手機文字與邊框間距

接續 R53（c5bb5735c06f0ce72372a9b6445a05952fa9ee5c），只調整 v5 開發版樣式與版本快取。

## 原因

- 460px 以下的工作紀錄表格轉為雙欄 Grid；原規則同時將列與儲存格的左右 padding 設成 0。
- 後續風格替 `.card` 加上完整邊框，但 `.table-shell` 沒有補上左右內距，因而讓加班、請假與假別額度的第一欄貼著外框。
- 表格標題使用 `.card-pad`，卻沒有同時帶 `.card`；舊版只修正 `.card.card-pad` 的規則未涵蓋這些標題。

## 檢查範圍與處理

| 區域 | 程式檢查結果與處理 |
| --- | --- |
| 加班、請假紀錄、假別額度 | 在未加內距的表格外框中，為手機資料列加入 16–24px 左右留白，隨既有文字密度設定調整。欄位採 `minmax(0,1fr)`，長標籤可換行。 |
| 補休來源、結算 | 已由外層 `.card.card-pad` 提供內距，不再次縮窄內容；共用按鈕間距與大字模式單欄規則。 |
| 假別額度、調薪歷程、年度公司核對表 | 補齊表格標題左右內距，包含假別額度空狀態。 |
| 加班差額試算 | 有框表格標題補齊上方與左右留白。 |
| 薪資、首頁近期紀錄 | 原卡片已有內距；文字欄允許縮排與換行，避免長名稱或英文撐出邊界。 |
| 公司、設定、投資標題 | 檢查既有卡片、彈窗及輸入欄位內距；補強文字收縮與手機標題／操作按鈕換行。 |
| 投資清單、持股與交易表 | 原清單有左右 14px 以上內距、表格儲存格有 12px 以上內距；保留既有橫向捲動與 FIFO 展開方式。 |
| 年度比較、報表、表單、備份與 Google Drive | 外層已有內距；保留寬表格捲動與既有表單寬度規則。 |

手機工作紀錄操作按鈕改為 8px 間距、至少 44px 高。大字模式在 460px 以下改為單欄，維持金額、狀態和標籤的可讀性。新增規則只作用於螢幕，不覆寫各風格背景、金框、動畫或列印樣式。

## 驗證與限制

- 16 個開發版 JavaScript 檔案通過 Node 語法解析；CSS 引號、註解、括號與區塊閉合檢查通過；`git diff --check` 通過。
- 與 R53 原始碼逐檔比對，應用程式、頁面及 service worker 除版本／快取標記外沒有邏輯改動；Schema 15、資料 KEY、薪資與投資計算、備份及 Google Drive 流程不變。
- 檢查涵蓋所有共用框線／留白規則與上述頁面模板，並確認巢狀卡片不會重複加上內距。
- 發布流程另執行 worker 建置、單一 HTML 打包及 16 段內嵌 JavaScript 語法驗證，並確認凍結 v4.3.2 檔案沒有異動。
- 依使用者要求未使用虛擬瀏覽器。本次為原始碼與封裝檢查，尚未進行手機實機視覺驗收，不能宣稱實機 PASS。
