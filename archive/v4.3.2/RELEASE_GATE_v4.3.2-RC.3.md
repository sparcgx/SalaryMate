# SalaryMate v4.3.2-RC.3｜薪資清單版面修正

日期：2026-09-30。承接 RC.2，維持 Web 發布候選。

## 使用者回報與修正

1. 圖一搜尋區塊過高：RC.2 的 `flex-basis: 26rem` 在手機直向 Flex 排列時成為高度，覆蓋原有 mobile 規則。改用專屬 Grid 工具列；桌機搜尋與新增操作同列、手機搜尋與操作分兩列，搜尋高度由輸入框自然決定，移除大面積空白。
2. 圖二操作按鈕分行：核對狀態原本插在月結核對及編輯之間，block 元素造成換行。將「月結核對／編輯／刪除」置於同一個不換行的水平按鈕組，核對狀態移到按鈕組下方。手機觸控高度 44 px，維持表格內橫向捲動。

本次只有上述薪資清單標記、CSS 與版本識別變更；計算、資料格式、儲存、備份及按鈕動作保留 RC.2。
