# SalaryMate v4.3.2-dev.3｜補休來源、餘額、到期與結算

## 已實作
- 在每日加班紀錄選「轉補休」，指定部分或全部時數及到期日。每筆加班最多建立一筆來源；轉入時數從該筆預估加班費排除，剩餘時數按原有倍率估算。若歸屬薪資月已列入加班金額，阻止轉入，先核對薪資。
- 補休帳本顯示每筆加班來源、公司、取得／使用／結算／餘額、到期日及已到期未結算。到期日依實際約定手動輸入；不自動設定法定年限或核銷到期餘額。
- 新的補休請假可選擇連結帳本。僅已確認且連結的請假依來源到期日先後扣除；不足、跨公司、來源已到期時阻止儲存。舊請假預設不連結，避免自動扣除既有歷史餘額。
- 結算須指定來源、實際日期、時數、金額與備註；結算不自動寫入薪資明細。可撤銷結算；未使用、未結算的轉入也可撤銷。已轉入來源的加班不得編輯或刪除。資料存於原 Schema 13 狀態及 JSON 備份。
- 變更來源會使相關薪資月結核對需重新核對。來源遺失或餘額異常顯示警告。

## 實機驗收建議
1. 選一筆尚未列入既有薪資加班金額的加班，轉入部分時數，設定到期日；查看預估加班費及帳本來源。
2. 建立已確認補休請假並勾選扣帳，確認餘額；超額及到期後日期應阻止。
3. 記錄部分結算金額，再撤銷；核對餘額與原薪資紀錄保持一致。
4. 備份、重新載入此版本還原，核對來源、餘額、結算及既有薪資資料。舊版軟體可能不保留新欄位，回退前須先保存備份。

## 邊界與狀態
結算金額屬人工核對紀錄，不自動代表公司已支付，也不產生薪資加項。不同工作規則的補休折算、到期與現金計價依公司約定／適用規範確認，程式不自動套用法規。
